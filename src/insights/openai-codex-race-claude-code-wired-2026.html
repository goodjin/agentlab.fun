Inside OpenAI's Race to Catch Up to Claude Code

★★★★★ 5星
来源: Wired | 作者: Maxwell Zeff | 2026-03-11

核心发现

为什么 AI 领域最大的公司会在 AI 编码革命中落后？Wired 通过 30+ 内部人士采访，揭示了 OpenAI 在 AI 编码领域追赶 Anthropic 的内部故事。

关键数据

  • Claude Code: 年化收入 $2.5B，占 Anthropic 业务的近 1/5
  • OpenAI Codex: 年化收入刚超过 $1B
  • 2021 年 OpenAI 就演示过 Codex，但因 ChatGPT 发布而暂停

深度分析

  • 先发优势丧失: Altman 表示 "First to market is worth a lot"，但 ChatGPT 的成功让公司忽视了 Codex
  • Anthropic 的专注: 更早专注编程，从真实代码仓库学习，而非学术竞赛
  • 内部混乱: 多个团队做不同产品，后来才合并成统一的 Codex
  • 战略转折: Codex 是"最有可能通往 AGI 的路径"

行业影响

AI 编码 agent 是企业愿意付费的少数领域之一，Altman 称之为"罕见的万亿美元市场"。
