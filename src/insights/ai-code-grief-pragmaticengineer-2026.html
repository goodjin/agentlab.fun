当AI编写大部分代码时的失落感

来源: The Pragmatic Engineer | 发布: 2026-03 | 作者: Gergely Olympi
"I'm coming to terms with the high probability that AI will write most of my code which I ship to prod, going forward."

一位工程师的内心独白

作者分享了他面对AI编写代码时的真实情感：

  • 编程是一项花了大量时间才精通的技能
  • 曾记得大学第一堂编程课的迷茫
  • 记得第一份工作的复杂代码库
  • 记得花了多年实践、学习才变更好

而现在，AI可以更快、更好地完成这些工作。

失去的是什么？

编码的乐趣

"被'锁定'的状态，平衡多个想法，打字时进入zone，然后编译运行，看到'YES'——它如预期工作了！"这是编程最美好的回忆。

心流体验

曾经需要高度专注的复杂编程工作，现在AI可以更快完成。这种"爱恨交织"的关系似乎要结束了。

未来的可能

也许随着AI代理技术，"在zone中"的状态会转向：

  • 思考更高层次的问题
  • 指导AI编写更复杂的代码
  • 从"做"变成"审"
"Or perhaps with AI agents, being 'in the zone' will shift to thinking about higher-level problems, while instructing more complex code to be written?"

核心问题

  • 🤔 AI是否会让"编写复杂代码"失去价值？
  • 🤔 工程师的成就感从何而来？
  • 🤔 职业身份如何重新定义？
  • 🤔 "知道如何验证代码"是否变得比"知道如何写代码"更重要？

给工程师的思考

这不是关于AI是否会取代工程师的問題，而是关于：

  • 接受变化：AI不是威胁，而是工具进化
  • 重新定位：从"写代码"转向"设计、审查、指导"
  • 保持好奇：持续学习新技术，保持竞争力
  • 找到新的满足感：也许来自解决更高层次的问题
