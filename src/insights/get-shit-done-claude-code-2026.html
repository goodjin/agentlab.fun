🚀 get-shit-done: Claude Code 元提示框架

AI Claude Code 元提示 开发工具 ⭐⭐⭐⭐ 4星
摘要: 轻量级但强大的元提示和上下文工程系统，专为 Claude Code、OpenCode、Gemini CLI、Codex 等 AI 编码工具设计
"If you know clearly what you want, this WILL build it for you. No bs."

🎯 解决的问题

上下文腐化 (Context Rot) — 随着 Claude 填满其上下文窗口而发生的质量下降问题

⚙️ 核心技术

  • 上下文工程 (Context Engineering)
  • XML 提示格式化
  • 子代理编排 (Subagent Orchestration)
  • 状态管理 (State Management)

💻 安装

# 交互式安装
npx get-shit-done-cc@latest

# 非交互式安装 - Claude Code
px get-shit-done-cc --claude --global  # 全局安装
npx get-shit-done-cc --claude --local   # 本地安装

# 非交互式安装 - OpenCode
npx get-shit-done-cc --opencode --global

# 非交互式安装 - Gemini CLI
npx get-shit-done-cc --gemini --global

# 非交互式安装 - Codex
npx get-shit-done-cc --codex --global

# 验证安装
