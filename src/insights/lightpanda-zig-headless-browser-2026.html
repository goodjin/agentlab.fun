🐼 Lightpanda: 用 Zig 编写的 AI 原生无头浏览器

AI 浏览器 Zig 自动化 ⭐⭐⭐⭐⭐ 5星
摘要: 专为 AI 代理和自动化设计的轻量级无头浏览器，用 Zig 从头编写，不是 Chromium 分支

🚀 核心性能优势

9x
更少内存
11x
更快速度
0ms
即时启动

🔧 技术特性

  • 非 Chromium 分支: 从头用 Zig 编写的全新浏览器引擎
  • CDP 兼容: 支持 Puppeteer、Playwright、chromedp
  • 完整 Web 支持: JavaScript 执行、Web APIs、XHR、Fetch
  • 网络功能: Cookie、代理支持、网络拦截、robots.txt
  • 跨平台: Linux x86_64、macOS aarch64 支持

📦 安装方式

# Linux
curl -L -o lightpanda https://github.com/lightpanda-io/browser/releases/download/nightly/lightpanda-x86_64-linux && chmod a+x ./lightpanda

# macOS
curl -L -o lightpanda https://github.com/lightpanda-io/browser/releases/download/nightly/lightpanda-aarch64-macos && chmod a+x ./lightpanda

# Docker
docker run -d --name lightpanda -p 9222:9222 lightpanda/browser:nightly

💡 为什么选择 Lightpanda?

现代网页离不开 JavaScript，传统的 HTTP 请求无法获取动态内容。但 Chrome 浏览器太重，不适合大规模自动化。Lightpanda 填补了这个空白:

  • AI 代理: 为 AI 助手提供轻量级网页交互能力
  • LLM 训练: 大规模网页数据采集
  • 网页抓取: 高效替代传统无头浏览器
  • 自动化测试: 快速执行测试用例

🔬 技术栈

  • 语言: Zig 0.15.2
  • JavaScript 引擎: v8
  • HTTP 客户端: Libcurl
  • HTML 解析: html5ever
