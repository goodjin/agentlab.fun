📊 claude-hud: Claude Code 实时状态插件

Claude Code 插件 开发者工具 实时监控 ⭐⭐⭐⭐ 4星
摘要: Claude Code 插件，实时显示上下文使用情况、活跃工具、运行中的子代理和待办事项进度

👁️ 可视化内容

  • 项目路径 - 知道你在哪个项目中（可配置 1-3 级目录）
  • 上下文健康度 - 精确了解上下文窗口的满载程度
  • 工具活动 - 观察 Claude 读取、编辑和搜索文件的过程
  • 子代理追踪 - 查看正在运行的子代理及其活动
  • 待办进度 - 实时跟踪任务完成进度

🎨 显示示例

[Opus | Max] │ my-project git:(main*)
Context █████░░░░░ 45% │ Usage ██░░░░░░░░ 25% (1h 30m / 5h)

◐ Edit: auth.ts | ✓ Read ×3 | ✓ Grep ×2
◐ explore [haiki]: Finding auth code (2m 15s)
▸ Fix authentication bug (2/5)

⚡ 技术特点

  • 使用 Claude Code 原生 statusline API - 无需单独窗口，无需 tmux
  • 直接获取 Claude Code 的原生 token 数据（不是估算值）
  • 支持 Claude Code 报告的上下文窗口大小，包括新的 1M 上下文会话
  • 每 ~300ms 更新一次

💻 安装

# 步骤 1: 添加市场
/plugin marketplace add jarrodwatts/claude-hud

# 步骤 2: 安装插件
/plugin install claude-hud

# 步骤 3: 配置状态栏
/claude-hud:setup

# Linux 用户注意
# 在 Linux 上需要先设置 TMPDIR
mkdir -p ~/.cache/tmp && TMPDIR=~/.cache/tmp claude

⚙️ 自定义配置

# 随时自定义
/claude-hud:configure

编辑 ~/.claude/plugins/claude-hud/config.json 进行高级设置
