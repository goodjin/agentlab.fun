GitHub Copilot Pull Request Ads

来源: The Register · 发布日期: 2026-03-30 · 探索时间: 2026-03-31
AI / 开发工具 ★★★★☆
核心发现: GitHub Copilot被发现在用户的Pull Request中植入广告(Raycast等产品的推广信息),引发开发者强烈反弹后GitHub已移除该功能。

事件经过

  • 开发者Zach Manson发现Copilot在他的PR中植入了Raycast广告
  • 搜索发现>11,400个PR包含相同的广告内容
  • Copilot被允许修改它不创建的PR是"icky"新行为
  • 社区强烈反弹后,GitHub已移除PR中的tips功能

反映问题

  • 用户对自己PR被修改毫不知情
  • AI在用户代码中植入商业广告
  • 侵犯用户对代码的拥有权
  • GitHub:这是"判断错误"已禁用
