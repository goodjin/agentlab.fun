🏢 Noosa Labs - 收购 micro-SaaS 达到 $120k MRR

⭐⭐⭐⭐⭐ 5星 | 来源: Indie Hackers | 2026-03-17

SaaS 收购 创业 $120k MRR 投资组合
📈 $120k MRR 🏢 3 个产品 📦 Sendtric, Evalart, Mava 🌍 巴黎/旧金山

什么是 Noosa Labs？

Noosa Labs 是一个小型盈利 SaaS 企业的连续收购者。他们收购非常盈利的 SaaS 企业（$200k-$600k ARR，50%+ 利润率），主要面向 SMB 产品驱动增长。

📦 当前产品组合：
  • Sendtric — 邮件活动倒计时计时器
  • Evalart — 招聘技能评估平台
  • Mava.app — AI 支持平台

创始人背景

Pascal Levy-Garboua 在科技领域工作了 23 年：

  • VirtuOz — AI 聊天机器人公司，后被 Nuance Communications 收购（现属微软）
  • 图像识别初创公司 — 发明照片搜索，后被 Yahoo 收购为 Flickr 搜索提供支持
  • 本地配送初创公司 — 在旧金山创业，后失败
  • Checkr — 第 9 号员工，离职时公司年营收超过 $250M
  • 天使投资人 — 13 年，投资了 Notion, Checkr, Baseten 等
⚠️ 平台风险教训：
第一个收购的产品 WAMessages（WhatsApp Chrome 扩展）在重新设计后大幅增长并盈利，但 2022 年 12 月收到 WhatsApp LLC 的停止销售函，必须关闭。9 个月才恢复。这次经历教会他们不要依赖大平台。

收购策略

  • 目标规模： $200k-$600k ARR，50%+ 利润率
  • 客户群体： SMB，产品驱动增长
  • 发现渠道： Constellation Software 模式，Acquire.com 市场
  • 技术栈偏好： 简单栈，避免异国或过于复杂的技术

产品技术栈

  • Sendtric： RoR 和 Go
  • Evalart： PHP 和 React
  • Mava： TypeScript 和 Svelte

收入和增长策略

  • 定价提高和新套餐： Sendtric 引入 Enterprise 和 API 计划加速增长
  • 定价简化： Evalart 定义明确定价，摆脱大幅折扣
  • 改进入职和减少流失： Sendtric 更新入职流程，新增 widgets，成功将流失降低 20-30%
  • 产品改进： 成为产品领导者同时保持价值定价

获取用户渠道

  • SEO
  • 口碑： Sendtric 在邮件营销者中的声誉
  • 病毒功能： 客户在其他 Discord 服务器发现 Mava AI 机器人
  • Google Ads： Evalart
  • 外展和产品合作： 最近开始，三分之一管道

创始人建议

  • 保持耐心： 找到产品市场匹配总是比在 X 上读到的需要更多时间
  • 避免平台有 kill switch 的企业
  • 更关注增长举措 而不是产品改进或新功能
  • 寻求帮助和反馈 — Indie Hackers 社区非常慷慨

未来展望

2026 年目标：加速 Mava 和 Evalart 增长，用企业客户扩展 Sendtric，完成一次新收购。探索 Claude Code 趋势，重新思考长期战略。认为像他们这样的公司有机会成为其他创始人的"发行中心"（类似唱片标签模式）。
