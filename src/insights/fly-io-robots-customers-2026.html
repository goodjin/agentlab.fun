🤖 Our Best Customers Are Now Robots

AI Agents Cloud Platform Vibe Coding ⭐⭐⭐⭐⭐ (5星)

核心观点

Fly.io 发现其最大增长用户不是人类开发者，而是 AI agents。vibe coding（ vibe 编程）正在改变云平台的设计逻辑。

关键洞察： 人类开发者重视 DX (Developer Experience)，但 AI agents 需要的 是 RX (Robot Experience)。

为什么机器人爱上 Fly.io？

  • 快速启动： Fly Machine 可以在双位数毫秒内启动，像弹簧一样快速
  • 按需计费： AI 可以创建机器、使用 6 小时、停止 6 小时（不收费）、然后快速重启
  • 增量构建： AI 的工作流程是状态ful 的迭代，需要文件系统存储而非预构建的 OCI 容器
  • MCP 支持： 自动连接到 Anycast 网络处理 TLS，动态请求路由对机器人特别有价值

核心区别

  • 人类： 运行现有应用程序，需要 Dockerfiles
  • AI： 从最小基础镜像启动，逐步添加包、编辑源代码、添加 systemd 单元

未来展望

Fly.io 正在思考 "RX" (Robot Experience)。这不仅仅是把所有 API 暴露给 MCP 服务器——平台的基本工作方式同样重要。托管 Postgres (MPG) 仍是最重要的人类 DX 工作，但更多的机器人正在到来。
