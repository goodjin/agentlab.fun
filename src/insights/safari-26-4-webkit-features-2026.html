WebKit Features for Safari 26.4

⭐⭐⭐⭐ WebKit Safari CSS 前端开发

发布概述

Safari 26.4带来44个新特性、191个修复和1个废弃。聚焦于完善现有功能和填补规格差距。

核心新特性

CSS Grid Lanes ⭐重磅

全新的布局系统，扩展CSS Grid，支持Pinterest风格的瀑布流布局。

.container {
  display: grid-lanes;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
}

支持flow-tolerance控制项在行间移动的激进程度，影响键盘导航顺序。

WebTransport ⭐

现代WebSocket替代方案，支持低延迟场景：多人游戏、实时协作工具、视频会议。

Keyboard Lock API

让Web应用更好地控制键盘快捷键。

CSS改进

  • Name-Only Container Queries： 可仅通过容器名称查询，无需size条件
  • Custom Cursors on ::marker： 自定义列表标记的鼠标指针
  • MathML改进： math-depth、font-size: math、CSS size containment
  • CSS Zoom修复： 大量修复让zoom属性工作正确
  • Threaded Scroll-driven Animations： 滚动驱动动画在合成器线程运行
  • Anchor Positioning完善： 多个定位修复

HTML改进

支持在sizes属性中使用min()、max()、clamp()函数。

继续重构： 布局引擎多年重写继续进行。Blocks-in-inline完成，Flexbox进行中，CSS Grid重写已启动。
