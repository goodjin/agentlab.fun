OpenCode - Open Source AI Coding Agent

AI 编码代理 开源 ⭐⭐⭐⭐⭐ (5星)

120K GitHub stars 的开源 AI 编码代理，挑战 Claude Code 和 Cursor 的新势力。

核心洞察: 开源 AI 编码代理挑战 Claude Code/Cursor，隐私优先设计。

核心特性

  • LSP 自动启用：自动加载正确的语言服务器
  • 多会话：同一项目可启动多个并行的代理
  • 分享链接：可分享任何会话用于参考或调试
  • 任意模型：支持 75+ LLM 提供商，包括本地模型
  • 多形态：终端、桌面应用、IDE 插件

模型支持

  • 内置免费模型
  • 连接任意模型：Claude, GPT, Gemini 等
  • GitHub Copilot：登录使用 Copilot 账号
  • ChatGPT Plus/Pro：登录使用 OpenAI 账号
  • Models.dev：75+ LLM 提供商

Zen 优化模型

Zen 提供针对编码代理测试和基准验证的 AI 模型，无需担心跨提供商的性能和质量不一致。

隐私优先

OpenCode 不存储任何代码或上下文数据，可在敏感环境中运行。
