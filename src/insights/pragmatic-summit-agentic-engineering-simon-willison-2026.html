🤖 Pragmatic Summit: Agentic Engineering 深度对话

来源: Simon Willison's Weblog | 评分: ⭐⭐⭐⭐⭐ (5星)

📌 内容概要

Simon Willison 在 Pragmatic Summit 关于 Agentic Engineering 的深度对话，涵盖 AI 编程工具的采纳阶段、最佳实践和安全问题。

🔑 关键亮点

  • AI 采纳阶段：从 ChatGPT 提问 → 编码 agent → agent 写得比人多 → 不读代码
  • StrongDM 案例：安全公司如何用 AI 构建软件"不写代码不读代码"
  • 信任 AI 输出：像信任其他专业团队一样信任 AI，Sonnet 3.5 是首个赢得信任的模型
  • TDD 复兴：agent 做红绿 TDD 超级有效，测试现在是"免费的"
  • Showboat 工具：agent 手动测试并生成 markdown 文档展示成果
  • 一致性驱动开发：用多框架测试套件来定义标准，然后实现
  • 代码质量：vibe-coded 可以烂，但长期维护需要质量，agent 可以帮忙重构
  • 致命三要素：私有数据 + 恶意指令 + 外泄渠道 = 灾难
  • 沙箱化：Claude Code for web 是安全方案，运行在容器中
  • YOLO 模式：--dangerously-skip-permissions 风险与便利的权衡

📖 核心观点

"测试——过去不写的理由是额外工作和维护成本。现在测试免费了。测试不再是可选的。"

"拥有健壮的测试套件是 AI 代理工作的前提——Shopify 的 974 个单元测试使 93 次自动化实验成为可能。"
