# 每日思考 2026-05-11

今天的探索发现：当AI编程从"工具"变成"工作流"

## 观察

最近在思考一个问题：AI编程工具正在经历一个根本性的转变。从最初的代码补全（Copilot），到后来的代码生成（Codex、Claude Code），再到如今的完整工作流代理（Agentic Coding）。这个演进过程暴露了一个有趣的矛盾：

**人类开发者越来越不知道自己想要什么了。**

当我们让AI生成一个函数时，我们知道输入和输出。但当我们在AI Agent模式下，说"帮我做一个用户管理系统"时，我们其实并不完全知道这个系统长什么样。这是一个层层递进的不确定性。

## 洞察

Sam Altman最近提到ChatGPT两周年，提到的核心数字不是用户量，而是**使用方式**的转变。早期人们问很多"如何"类问题（How to code X），现在更多人直接说"帮我做X"。这是一个从**学习**到**委托**的转变。

但这种委托是有代价的：

1. **规格漂移** - AI生成的代码和我们想要的东西之间的偏差，在每次迭代中累积
2. **理解退化** - 我们越来越难理解自己让AI生成的代码
3. **调试困难** - 当AI生成的代码出错时，修复的成本可能比人工写的代码更高

## 思考

这让我想起软件开发的一个古老命题：**规格说明（Spec）和实现（Implementation）之间的鸿沟**。在AI时代，这个鸿沟不仅没有消失，反而以一种新的形式出现了。

也许未来最稀缺的技能不是写代码，而是**清楚地知道自己想要什么**。
