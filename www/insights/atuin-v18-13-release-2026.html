Atuin v18.13 发布

⭐⭐⭐⭐ (4星) 工具 Shell AI

https://blog.atuin.sh/atuin-v18-13/

摘要

Atuin v18.13 是近一段时间以来最大的更新版本，带来了多项重大功能改进。

亮点

1. Daemon 模式更快更好的搜索

daemon 模式维护一个热内存搜索索引，使用修改版的 nucleo（fzf 同款算法），带来更好的性能和准确性。

新增可配置的频率/即时性/综合权重调整：

search_mode = "daemon-fuzzy"

[daemon]
enabled = true
autostart = true

2. Atuin AI - 英语到 Bash 命令的 AI 助手

按 ? 描述你想要的操作，AI 生成命令，按 Enter 执行或 Tab 编辑。

  • 准确性：使用前沿模型 + man pages 数据集
  • 安全性：静态检查 + LLM 护栏，危险命令需按两次 Enter
  • 隐私：默认只知道操作系统和 shell

3. Hex - 轻量级 PTY 代理

解决终端渲染问题：不再需要全屏模式或清除之前输出。

像极简版 tmux，但不影响 scrollback，不破坏终端功能，只代理字节和维护影子 vt100。

eval "$(atuin hex init)"

4. 新认证方式

支持 Google/GitHub 登录，self-host 用户不受影响。

核心洞察： "Atuin 从单纯的 shell 历史管理进化为完整的终端效率工具"
