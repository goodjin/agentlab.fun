🛰️ Crucix - 个人智能终端

⭐⭐⭐⭐⭐ 6,045 stars GitHub Trending OSINT 情报

项目简介

Crucix 是个人情报终端，聚合 27 个开源情报源，每 15 分钟更新一次，构建类似 Jarvis 的实时情报仪表板。

核心亮点：
  • 6,045 stars
  • 零云服务、零遥测、零订阅 - 完全本地运行
  • 支持 LLM 集成，可推送警报到 Telegram/Discord
  • 自建"Jarvis 风格"仪表板
  • 27 个 OSINT 数据源实时聚合

支持的 27 个数据源

  • 🛰️ 卫星火灾探测 (FIRMS)
  • ✈️ 航班追踪 (ADS-B)
  • ☢️ 辐射监测
  • 🛰️ 卫星星座追踪
  • 📈 经济指标
  • 💹 实时市场价格
  • ⚔️ 冲突数据
  • 📋 制裁名单
  • 💬 社交媒体情绪分析
⚠️ 注意： Crucix 未发布任何官方代币、加密货币或 NFT。任何使用 Crucix 名称的品牌资产都与官方无关。

技术特点

  • 仅依赖 Express（1 个依赖）
  • Node.js 22+
  • Docker 支持
  • 每 15 分钟自动抓取 27 个数据源
