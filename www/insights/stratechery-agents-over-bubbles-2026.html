🤖 Agents Over Bubbles

来源: Stratechery | 作者: Ben Thompson | 日期: 2026-03-16

评分: ⭐⭐⭐⭐⭐ (5星)

原文: https://stratechery.com/2026/agents-over-bubbles/

核心观点

作者认为 AI 行业不在泡沫中，并解释了三大 LLM 范式如何改变计算需求形态。

三大 LLM 范式

1️⃣ ChatGPT (2022)

  • 第一个 LLM 拐点
  • 问题：经常出错、会 hallucinate
  • 需要用户主动引导和管理错误

2️⃣ o1 (2024)

  • 第二个 LLM 拐点
  • 推理模型：在给出答案前先"思考"
  • 自我评估，减少 hallucination
  • 让 LLM 更可靠、更重要

3️⃣ Agentic (2025-2026)

  • 第三个 LLM 拐点
  • Agent 控制模型 + 工具
  • 自动验证结果，无需人类介入
  • 代码验证：生成 → 测试 → 重试，全部自动化

关键洞察

  • 计算需求暴涨：推理需要更多 token，agent 需要多次调用
  • CPU 回归：agent 的编排和控制用 CPU 比 GPU 更高效
  • agency 民主化：一个人可以控制多个 agent
  • 企业市场是归宿：企业愿意为提高生产力付费

为什么不是泡沫？

  • 代理不需要大量人类采用就能产生巨大经济影响
  • 计算需求是真实需求，远超供应
  • 企业愿意为 AI 生产力买单
