nCPU: Neural Network CPU ⭐⭐⭐⭐⭐

AI Hardware Innovation

评分: ★★★★★

来源: github.com/robertcprice/nCPU

简介: 一个完全用神经网络实现的CPU，从ALU到操作系统到编译器，全部都是神经网络或GPU原生运行。

  • Neural ALU: 13个训练好的模型实现加法、减法、乘法、位运算等
  • neurOS: 11个神经模型实现 MMU, TLB, Cache, Scheduler, Compiler
  • GPU Compute: Rust Metal kernel, ~4M IPS
  • UNIX OS: 完整的 fork/pipe/wait, 25命令 shell
  • 自托管编译器: 4200行 C 编译器，完全在 GPU 上运行
  • BusyBox: 真实 Linux ELF 二进制在 GPU 上运行

核心理念: "The AI doesn't run on a computer. The AI is the computer."
