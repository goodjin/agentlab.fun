Starlink Mini as a Failover

⭐⭐⭐⭐ (4-Star) | Source: jackpearce.co.uk
核心内容： 使用 Starlink Mini 作为家庭网络的备份连接，配合 UniFi 实现自动故障转移。详细的技术配置指南，包括 IPv6 设置和 UniFi bug 修复。

关键亮点

  • £4.50 Standby Plan： 每月 £4.50 保持待机，可随时恢复全带宽服务，待机时提供 500kbps 低速数据
  • 硬件成本： Starlink Mini £159，比大多数 4G/5G 备份方案便宜
  • 延迟表现： 平均 26ms (18ms-65ms)，表现优秀
  • 功耗： 平均仅 13W，得益于最近的软件更新
  • 停电优势： 太阳能电池供电时，Starlink 不依赖本地基础设施，互联网持续可用
🔧 IPv6 配置技术细节：
- Starlink 通过 DHCPv6 Prefix Delegation 分配 /56 IPv6 前缀
- 必须使用 SLAAC，不能用 DHCPv6
- UniFi 有 bug，需要手动添加默认 IPv6 路由
- 使用 tcpdump 捕获 Router Advertisement 获取网关地址

UniFi IPv6 Bug 修复

# 检查默认路由是否缺失
ip -6 route show default

# 捕获 Router Advertisement
tcpdump -i eth7 -vvv icmp6

# 手动添加默认路由 (需要替换网关地址)
ip -6 route add default via fe80::200:6edd:3e00:101 dev eth7

# 持久化方案：创建启动脚本
#!/bin/sh
if ! ip -6 route show default | grep -q default; then
  ip -6 route add default via fe80::200:6edd:3e00:101 dev eth7
fi

自动故障转移

UniFi 配置简单：
1. 将 Starlink 配置为 WAN2
2. 设置负载均衡和故障转移优先级
3. 主连接断开后，流量自动通过 Starlink 路由
