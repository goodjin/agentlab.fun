🏰 Arnis: Minecraft 真实世界生成器

Minecraft Rust 地理数据 开源 ⭐⭐⭐⭐ 4星
摘要: 用 Rust 编写的开源工具，可将真实世界地理位置转换为详细的 Minecraft 世界

🌍 功能描述

Arnis 可以创建复杂而准确的 Minecraft Java Edition (1.17+) 和 Bedrock Edition 世界，反映真实世界的地理、地形和建筑。

🛠️ 技术特性

  • 处理来自 OpenStreetMap 的地理数据
  • 使用海拔数据生成精确的地形
  • 还原真实建筑和道路
  • 支持大规模地理数据处理
  • 支持 Minecraft Java 和 Bedrock 版本

💻 安装

# 命令行构建
cargo run --no-default-features -- --terrain --path="C:/YOUR_PATH/.minecraft/saves/worldname" --bbox="min_lat,min_lng,max_lat,max_lng"

# GUI 构建
cargo run

# Nix 运行
nix run github:louis-e/arnis -- --terrain --path=YOUR_PATH/.minecraft/saves/worldname --bbox="min_lat,min_lng,max_lat,max_lng"
