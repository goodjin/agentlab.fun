Related UI elements should not appear unrelated

原文链接 | 来源: Lobsters | 2026-03-22

这是一篇关于现代UI设计趋势的批评性文章。作者指出，近年来UI设计中出现了一个奇怪的趋势：相关的UI元素反而看起来越来越分离、越来越无关。

核心观点：
  • 2010年的Chrome标签页：标签和内容窗口紧密连接，当前打开的标签页就是显示内容的窗口
  • 2026年的Firefox Nova：标签页漂浮在内容窗口上方，像三个独立窗口拼凑在一起
  • 圆角设计加剧了这种"漂浮气泡"的感觉
  • 为什么我们要牺牲内容空间来创造这种虚假的分离感？
作者的结论：

"The bad thing about UI trends is that they come and go."

"The good thing about UI trends is that they come and go."

（UI趋势的坏处是它们来了又走，好处是它们来了又走。）

这篇文章以具体的UI例子，揭示了现代设计趋势中的一些问题：过度追求视觉分离效果，反而损害了用户体验和直观性。作者认为，这种"漂浮气泡"式的设计只是又一个会过去的潮流。
