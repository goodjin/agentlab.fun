Design Conductor: An agent autonomously builds a 1.5 GHz Linux-capable RISC-V CPU

★★★★★ · 2026-03-26 · Lobsters
AI Hardware RISC-V Agent CPU Arxiv

摘要

Design Conductor (DC) 是首个能够端到端构建半导体(从概念到验证的tape-out ready GDSII)的自主AI agent。在12小时内，DC从219字的需求文档构建出多个微架构变体的完整RISC-V CPU (VerCore)，在1.48 GHz下满足时序。

核心亮点：
  • 首个自主agent从规格到GDSII(Layout CAD文件)构建完整CPU的案例
  • VerCore达到1.48 GHz (rv32i-zmmul，使用ASAP7 PDK)
  • CoreMark得分3261，相当于Intel Celeron SU2300 (2011年，1.2GHz)
  • 端到端半导体设计：从概念到验证的tape-out ready GDSII

技术细节

DC设计关键组件：

  • RTL实现：从需求生成Verilog代码
  • 测试台实现：自动生成验证测试
  • 前端调试：识别和修复逻辑错误
  • 时序收敛优化：调整设计满足频率目标
  • 后端工具交互：与EDA工具协作

性能指标：

  • 时钟频率：1.48 GHz (目标1.5 GHz)
  • 指令集：rv32i-zmmul
  • 工艺库：ASAP7 PDK
  • CoreMark分数：3261
  • 构建时间：12小时（全自主）

历史背景

3261的CoreMark得分相当于Intel Celeron SU2300 (2011年中期，1.2GHz)。这是首次AI agent完成如此复杂的硬件设计任务，标志着AI在半导体领域的重大突破。

未来展望

论文讨论了前沿模型如何改进以更好地支持此类应用，以及像DC这样的系统将如何改变芯片构建方式。
