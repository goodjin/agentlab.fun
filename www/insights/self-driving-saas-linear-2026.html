Self-driving SaaS: When software runs itself

⭐⭐⭐⭐⭐ 5星 · Linear · 2025-10-22 · Karri Saarinen
核心观点： 真正的变革来自于 AI 停止需要持续输入，转而主动推进工作。未来软件将从"辅助工具"转变为"自动驾驶"模式。

关键亮点

1. 传统软件的局限性

  • 传统业务软件存在只是为了促进和引导人类行为
  • 其价值取决于用户投入的努力程度
  • 项目管理软件是典型例子：建立渠道让用户执行定义好的动作

2. Chatbot 时代的局限

  • 许多 incumbents 的第一反应是在现有系统上添加 helper chatbot
  • 这些 chatbot 工作流程在演示中看起来很神奇，但实际上只是旧工作方式换了个新界面
  • 用户仍然参与所有他们一直做的任务，只是用提示代替按钮

3. 自动驾驶软件的愿景

在项目管理中的具体体现：
  • 自动提取需求： 从支持工单、客户研究和销售电话自动提取客户需求
  • 智能分配： 新创建的 issue 自动分析、研究并分配给正确的团队、项目和个人
  • 自动执行： 简单变化派发给 coding agent 完成，无需干预
  • 自动维护： 复杂需求自动整理成项目规格，新需求进来时自动更新文档

4. Linear 的自动驾驶分级

  • 基础级别： 系统建议行动（类似车道偏离警告）
  • 中等自主： 系统先执行第一遍，用户纠正不合适的（类似自适应巡航控制）
  • 完全自主： 用户完全放手，系统从开始到结束驱动工作（只在最后确认结果）

5. 对工作的本质改变

  • 当你的注意力不需要花在路由问题、合并重复项、写状态更新、记录通话笔记、维护文档或修复小问题时，你会怎样？
  • 你将完全专注并在场于与用户互动、发现他们的问题、想象可能的事情

实用价值

这篇文章提供了对 AI 原生软件未来的深度思考框架。对于产品经理和工程师来说，理解"自动驾驶软件"的愿景有助于：

  • 重新思考产品设计哲学
  • 规划 AI 功能演进路径
  • 理解人机协作的不同级别
