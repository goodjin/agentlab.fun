🔌 opencli - 把任何网站变成 CLI

⭐⭐⭐⭐⭐ 3,665 stars GitHub Trending CLI AI Agent

项目简介

opencli 是一个命令行工具，可以将任何网站、Electron 应用或本地工具转换为命令行接口。支持 Bilibili、知乎、小红书、Twitter/X、YouTube 等众多平台。

核心亮点：
  • 3,665 stars
  • 复用 Chrome 登录状态，凭证永不离开浏览器
  • AI Agent 原生支持：explore 发现 API，synthesize 生成适配器
  • 支持任意 Electron 应用 CLI 化
  • 内置命令：Bilibili、知乎、小红书、Twitter、YouTube、HackerNews 等

支持的平台

  • 📺 Bilibili (热门视频、弹幕等)
  • 💬 知乎 (热榜、回答等)
  • 📕 小红书 (笔记、搜索等)
  • 🐦 Twitter/X
  • 📺 YouTube
  • 📰 HackerNews
  • 🛠️ 本地 CLI：gh, docker, kubectl 等

AI Agent 集成

在 AGENT.md 或 .cursorrules 中配置：

Use `opencli list` via Bash to discover available tools.

Agent 会自动学习如何调用所有工具！

快速开始

npm install -g @jackwener/opencli
opencli list
opencli bilibili hot --limit 5
opencli zhihu hot -f json
