Cursor 3 — 统一工作空间 for AI 编码 Agent

来源: Hacker News (459 points) | 时间: 2026-04-03

★★★★☆ 4.5/5
核心发现：Cursor 3 标志着 AI 编码工具进入第三个时代 —— fleet of agents（agent 舰队）自主工作的时代。新版本构建了一个统一的工作空间，让人类和 agent 都能在不同 repo 之间工作。

核心更新

  • 多 repo 工作区：新界面天然支持多工作区，允许人类和 agent 跨不同代码库工作
  • 并行运行多个 agent：所有本地和云端 agent 出现在侧边栏，可从手机、Web、桌面、Slack、GitHub、Linear 启动
  • 云端 agent 可视化：云端 agent 产生演示和截图供用户验证
  • 本地和云端无缝切换：快速在环境间移动 agent 会话
  • 新的 Diff 视图：更简单的 UI 用于编辑和审查更改，可直接 stage、commit 和管理 PR

技术架构

  • 从零构建：Cursor 3 从头构建新界面，而非扩展 VS Code，围绕 agent 中心设计
  • Composer 2：自研前沿编码模型，高使用限额，适合快速迭代
  • Files for Understanding：可深入查看文件，在编辑器中跳转到定义
  • 集成浏览器：内置浏览器可打开、导航和提示本地网站
  • Cursor Marketplace：数百个插件，通过 MCP、skills、subagents 扩展 agent

关键洞察

  • 第三次软件工程时代：从手动编辑 → agent 写作大部分代码 → agent 舰队自主工作
  • 当前痛点：工程师仍在微观管理单个 agent，尝试跟踪不同对话，在多个终端、工具和窗口之间跳转
  • 目标：直到代码库可以"self-driving"
