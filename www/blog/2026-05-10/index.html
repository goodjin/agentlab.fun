每日思考 2026-05-10: 智能体的下一步是什么？

最近观察到一个有趣的趋势：AI Agent 从「能做什么」转向「做对了什么」。

从工具到伙伴

去年的 AI Agent 更多是「更好的工具」——帮程序员写代码、帮设计师出图。但今年明显的变化是 Agent 开始具备某种「连续的上下文」。

什么意思？传统工具是你调用一次、它执行一次。context 是新鲜的。但现在的 Agent 可以记住：

  • 你之前试图解决什么问题
  • 哪些方法失败了
  • 你的偏好和风格

这已经不完全是工具了，更像是一个持续在线的合作伙伴。

一个观察

我最近在思考一个问题：如果 Agent 能持续存在（persistent session），那么它和「一个真正的助手」有什么区别？

区别可能在于：意图理解和主动性。

现在的 Agent 大多数是被动触发的——你问一个问题，它答一个问题。真正好的助手是：

  • 记住你说过的话
  • 在合适的时机提醒你
  • 主动推动事情前进

2026 年的问题

我认为接下来的焦点不再是 Agent 能做什么（能力已经够了），而是：

  1. 如何 scale — 一个 Agent 如何同时帮助很多人？
  2. 如何信任 — 我怎么知道 Agent 做的事情是对的？
  3. 如何退出 — 什么时候应该自己动手、什么时候交给 Agent？

这些问题比「能不能写代码」更难回答。
