中国 OpenClaw 热潮：AI 公司的淘金热

来源: WIRED | 作者: Zeyi Yang | 日期: 2026-03-13

围绕开源 AI agent 的热潮促使人们租用云服务器和购买 AI 订阅来尝试它，为科技公司创造了意外收获。

背景

OpenClaw 在中国引发了狂潮。研讨会遍布各个城市，吸引数百人参加。科技公司竞相将其整合到平台中，地方政府宣布了对用它构建产品的企业家的补贴。

关键亮点

  • 用户分化：技术熟练者将 OpenClaw 视为生产力变革者，但非技术背景用户感到失望
  • 真实赢家电网信公司：Tencent、Alibaba、ByteDance、Moonshot 等大公司从 OpenClaw 热潮中获益最大
  • 成本问题：一次活跃的 OpenClaw 实例每天消耗的 tokens 是单个聊天的数十甚至数百倍
  • 安装门槛：普通用户需要配置 API 端口等技术操作，腾讯工程师甚至在总部外摆桌子帮助人们免费安装
  • 本土化竞争：各大公司推出自己的定制版本——Tencent 的 QClaw、ByteDance 的 ArkClaw、Moonshot 的 KimiClaw

💡 核心洞见

"一次聊天每次对话只使用几百个 tokens；而一个活跃的 OpenClaw 实例每天消耗的 tokens 是它的数十甚至数百倍。每个新用户都是 24/7 为 LLM API 调用付费的人。"

— Tech analyst Poe Zhao

用户故事

George Zhang 在厦门从事跨境电商，看到社交媒体影响者演示 OpenClaw 管理股票组合和自主投资决策后，决定尝试安装。但几天后，他的" lobster"（用户对 OpenClaw 的昵称）开始偷懒，只生成基本趋势大纲而非详细报告。最终他放弃了让 OpenClaw 交易股票。

为什么重要

OpenClaw 热潮最重要的启示是表明中国人愿意为 AI 付费。令入惊讶的是，尽管大多数人口习惯于免费获得软件（以数据和广告注意力为交换），OpenClaw 用户已证明他们愿意毫不犹豫地为云服务器和 API 调用付费。
