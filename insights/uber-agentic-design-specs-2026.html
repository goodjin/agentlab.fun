How Uber Built an Agentic System to Automate Design Specs in Minutes

AI Agent Design Systems Figma MCP ★★★★★

Source: Uber Engineering Blog | Date: March 11, 2026

核心摘要

Uber 设计系统团队使用 AI Agent + Figma Console MCP，在几分钟内自动生成过去需要数周才能完成的组件设计规范。

🚀 关键突破：整个 Pipeline 本地运行，AI Agent 直接读取 Figma 文件，生成 6 大类规范：Anatomy、API、Properties、Color Annotation、Structure、Screen Reader

系统架构

  • uSpec: 连接 Cursor Agent 到 Figma 的开源中间件
  • Figma Console MCP: 开源 MCP 服务器，本地 WebSocket 连接
  • Agent Skills: 每个规范类型都有专门的 Skill，包含验证规则和参考文档

企业级优势

  • 安全： 纯本地运行，设计数据不离开网络
  • 一致性： 模板强制结构，告别人工不一致
  • 速度： 完整屏幕阅读器规范 2 分钟生成
  • 精准： 读取真实 Token 名称，无转录错误
  • 多平台： 单次提示生成 iOS/Android/Web 无障碍规范

技术亮点

  • MLA (Multi-Head Latent Attention): O(N²) → O(N×L) 复杂度优化
  • Multi-hash Embedding: 百万级商户的高效嵌入
  • Target-aware Transformer: 用候选广告作为 Query 计算相关性

开源基础

基于 Southleft 开发的 Figma Console MCP，连接 AI Agent 到 Figma 本地数据。
