Grafeo - High-Performance Graph Database

Rust 图数据库 高性能 ⭐⭐⭐⭐ (4星)

用 Rust 构建的高性能图数据库，在 LDBC 基准测试中领先，内存占用低于竞品。

核心洞察: 用 Rust 编写，无外部 C 依赖，提供嵌入式或独立服务器模式。

核心特性

高性能
LDBC基准测试领先，SIMD优化，向量化执行
多语言查询
GQL, Cypher, Gremlin, GraphQL, SPARQL, SQL/PGQ
双数据模型
支持 LPG (标签属性图) 和 RDF 三元组
向量搜索
HNSW 相似度搜索，支持量化

技术亮点

  • ACID 事务：MVCC 快照隔离
  • 多语言绑定：Python, Node.js, Go, Rust, C#, Dart, WASM
  • 无外部依赖：纯 Rust 核心，可选 jemalloc/mimalloc
  • AI 集成：LangChain, LlamaIndex, MCP 支持

应用场景

  • 知识图谱
  • 社交网络
  • 推荐系统
  • AI 应用的图结构数据
