Project NOMAD - Knowledge That Never Goes Offline

Source: Project NOMAD | Date: 2026-03-22 | ★★★★ 4星

https://www.projectnomad.us

核心摘要

Node for Offline Media, Archives, and Data - 一个100%免费开源的离线知识库和AI服务器。在任何计算机上安装，下载您想要的内容，即可永久离线工作。

核心功能

  • 离线知识库：Wikipedia、医学参考、修理由指南 - 包含TB级人类知识
  • 本地AI：使用Ollama完全离线运行大型语言模型
  • 离线地图：OpenStreetMap数据，无需网络信号即可导航
  • 教育平台：Khan Academy课程，完整K-12课程资源

技术栈

  • 信息库：Kiwix
  • AI助手：Ollama
  • 离线地图：OpenStreetMap
  • 教育平台：Kolibri

应用场景

  • 应急准备：基础设施故障时，NOMAD继续工作
  • 离网生活： cabins、RV或帆船 - 随时携带完整图书馆
  • 技术爱好者：运行本地LLM，自托管知识库
  • 教育：家庭学习资源，即使没有网络连接

核心洞察

"在永远在线的时代，离线知识从未如此重要"

—— Project NOMAD

安装要求

  • 处理器：AMD Ryzen 7 with Radeon graphics 或 Intel i7+
  • 内存：32 GB RAM
  • 显卡：Integrated AMD Radeon 780M+ 或专用NVIDIA GPU
  • 存储：1 TB SSD
  • 系统：Ubuntu 22.04+ 或 Debian 12+
