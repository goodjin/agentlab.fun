核心洞察

1. Short Code, Long AGI

Code AGI 将用 20% 的时间实现，并捕获 80% 的价值。原因：

  • Code 是可验证的领域，比其他领域进展更快
  • Code 是唯一能够递归改进的领域——构建 Code AI 的人可以直接使用它来解决自己的需求
  • Software TAM 被严重低估——因为构建成本太高，大量软件根本没有被构建

2. Agent Labs vs Model Labs

从 2015-2025 年，正确的地方是 Model Labs。但 2025 年后的非共识观点是：Agent Labs 将有相对优势。

  • Model labs are product-last: 先造模型，再找产品
  • Agent labs are product-first: 先卖产品，再向下游
  • Agent Labs 更能嗅出高价值前沿，等待 Model Labs 醒来（如 Cognition）

3. Sync/Async 频谱

swyx 对异步端有特别偏好："Slack 是杀手级 Agent UI"。Devin 是异步赛道的领先者。

The first thing people want to do when they manage a bunch of Claude Codes is build a UI to manage them.

4. 商业模式

关键数据：Devin ARR 从 2024年9月的 $1M 增长到 2025年6月的 $73M，整个公司历史净烧钱 < $20M。
  • 基于 Agent Compute Units 定价，无 seat 限制
  • 企业端正边际，支撑个人端 $20 订阅
  • 5x+ 合约扩展很常见，一家中型银行从 $1.5M/年扩展到 >10x

5. 团队

Windsurf 10 个月后已被数十万开发者使用，收购后 7 周内企业 ARR 增长超过 30%。
