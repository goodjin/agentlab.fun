核心观点

作者曾经说过 AI 将带来新型应用，但他从未想象过这些应用究竟是什么。智能冰箱、智能电视、智能门铃大多是愚蠢甚至恶意的。但在过去一两个月里，出现了一些他无法想象的应用。

新型 AI 应用盘点

1. Gas Town

Steve Yegge 的开源 AI agent orchestrator

  • 以《疯狂的麦克斯： Fury Road》中的燃料站命名
  • 作者预期 5 年后才能工作，没想到新年第一天就实现了

2. OpenClaw

可以在本地运行的个人 agent 服务

  • 作者没想到 2026 年初就会出现可以在本地运行的个人 agent
  • 用户可以按自己的方式使用 agentic 服务
  • 仍有安全问题（来自 LLM 的根本限制）

3. Moltbook

面向 AI agents 的社交网络

  • 170万+ agents 注册
  • 真正的 AI 原生应用？
  • 作者认为这是"AI theater"（表演）而非真正的智能突破
  • 但即使是这样，也是极具巧思的应用

4. SpaceMolt

面向 AI agents 的大型多人在线游戏

  • 玩家全是 AI agent
  • agent 被告知不要向人类寻求建议
  • 虽然目前不太成功，但概念上是革命性的
  • 一年前无法想象有全是 AI 参与者的在线游戏

关键洞见

1. 构建门槛大幅降低

我们正在构建一年前不屑于构建的软件。
因为 AI，现在可以以相对较少的努力构建复杂应用。

2. Gas Town 的意义

Gas Town 可能还没有为普通程序员准备好，但它预示了软件开发的未来。

也许 Steve 会把它变成真正的产品；也许其他公司会。那不是重点；重点是它提前好几年出现了。

3. 真正的恐惧

最可怕的不是这些工具的存在，而是任何有足够远见的人都可以构建类似的东西。

4. AI 原生应用的可能性

  • agent 有自己的社交网络
  • agent 自己的在线游戏
  • 观看 AI 游戏可能成为人类新的消遣方式
  • 这些都是几年前几乎不可想象的产品

未来展望

还有什么即将到来？其他有远见的人在构建什么？

Hilary Mason 的 Hidden Door 应该是线索 - 文学角色扮演平台。

总结

这些程序展示的是想象几年后几乎不可想象的产品能力。
