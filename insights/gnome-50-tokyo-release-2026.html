🖥️ GNOME 50 "Tokyo" 发布

Linux 桌面环境 开源 ⭐⭐⭐⭐ 4星
摘要: GNOME 桌面环境第 50 个版本发布，以日本东京命名，感谢 GNOME.Asia Summit 2025 的组织者

👨‍👩‍👧‍👦 家长控制重大升级

  • 屏幕时间限制: 为儿童账户设置每日使用时间上限
  • 就寝时间: 设置 bedtime，自动锁定屏幕
  • 延长使用时间: 家长可灵活延长限制
  • 网页过滤后端: 新增内容过滤基础设施（UI 将后续更新）

感谢 Endless 基金会资助此功能开发

♿ 无障碍增强

  • Orca 屏幕阅读器: 全新的偏好设置窗口，自动语言切换
  • 浏览模式: 扩展到所有文档内容
  • 鼠标审查: 支持 Wayland 会话
  • 减少动画: 新增减少界面动画选项，减少不适和干扰

📝 文档标注功能

  • 文本注释: 轻松添加文字注释
  • 线条和高亮: 支持绘图和标注
  • 颜色选择: 多种颜色和线条粗细可选
  • 橡皮擦: 修正错误

📁 文件管理器改进

  • 更快缩略图: 缩略图和图标加载更快
  • 内存优化: 整体内存占用降低
  • 批量重命名: 更直观的界面，文本替换视觉高亮
  • 文件属性: 改为弹出式浮动窗口
  • 搜索筛选: 支持多条件筛选

🖥️ 远程桌面

  • 硬件加速: Vulkan 和 VA-API 视频解码，显著降低延迟和功耗
  • HiDPI 支持: 自动缩放匹配本地屏幕分辨率
  • 摄像头重定向: 远程会话中使用本地摄像头
  • Kerberos 认证: 企业级安全支持

🖼️ 显示技术

  • VRR 可变刷新率: 消除撕裂，如丝般顺滑
  • 分数缩放: 支持 125%、150% 等缩放级别
  • 低延迟光标: VRR 模式下光标独立于应用帧率

📅 其他改进

  • 日历: 参与者列表、ICS 导出、改进的月视图
  • 设置: 首周日期设置、音量控制改进

📅 发布日期: 2026-03-18

🔗 来源: GNOME 官方发布说明
