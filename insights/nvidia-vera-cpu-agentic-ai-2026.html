# NVIDIA Vera CPU: 首款专为 Agentic AI 设计的处理器 **来源**: [NVIDIA News](https://nvidianews.nvidia.com/news/nvidia-launches-vera-cpu-purpose-built-for-agentic-ai) **评分**: ⭐⭐⭐⭐⭐ (5星) **日期**: 2026-03-17 --- ## 核心亮点 NVIDIA 推出了 **NVIDIA Vera CPU**，这是全球首款专为 agentic AI 和强化学习时代设计的处理器： - **2倍效率**：与传统 CPU 相比，效率提升 2 倍 - **50%更快**：性能比传统 rack-scale CPU 快 50% - **88 个自定义 NVIDIA Olympus 核心** - **1.2 TB/s 内存带宽**：LPDDR5X 内存，带宽是通用 CPU 的 2 倍，功耗只有一半 ## 合作厂商 **部署 Vera CPU 的客户**： - Alibaba, ByteDance, Meta, Oracle Cloud Infrastructure - CoreWeave, Lambda, Nebius, Nscale **制造合作伙伴**： - Dell, HPE, Lenovo, Supermicro - ASUS, Compal, Foxconn, GIGABYTE, Pegatron, Quanta Cloud Technology, Wistron, Wiwynn ## 为什么 Agentic AI 需要专用 CPU 随着推理和 agentic AI 的进步，**规模、性能和成本越来越依赖于支撑模型的基础设施**——这些基础设施负责： - 规划任务 - 运行工具 - 与数据交互 - 运行代码 - 验证结果 ## Vera 的技术创新 ### 1. NVIDIA Spatial Multithreading 每个核心可以运行两个任务，提供一致、可预测的性能——非常适合运行许多并发任务的 AI 工厂。 ### 2. 第二代低功耗内存子系统 - 基于 LPDDR5X 内存 - 1.2 TB/s 带宽 - 带宽是通用 CPU 的 2 倍，功耗只有一半 ### 3. 与 GPU 集成 作为 **Vera Rubin NVL72** 平台的一部分，Vera CPU 与 NVIDIA GPU 通过 **NVLink-C2C** 互连技术配对： - 1.8 TB/s 一致性带宽 - 是 PCIe Gen 6 带宽的 7 倍 ## 生态系统支持 **Cursor** 正在采用 NVIDIA Vera 来提升 AI 编码 agent 的性能： > "We’re excited to use NVIDIA Vera CPUs to improve overall throughput and efficiency so we can deliver faster, more responsive coding agent experiences for our customers." — Michael Truell, CEO of Cursor **Redpanda** 测试显示： - 与 Apache Kafka 兼容工作负载相比，Vera 延迟降低 **5.5 倍** ## 部署规模 - **Vera CPU rack**：集成 256 个液冷 Vera CPU - 可维持超过 **22,500 个并发 CPU 环境** - 每个环境独立运行全性能 - 单个 rack 可部署数万个并发实例和 agent 工具 ## 市场意义 Jensen Huang 表示： > "Vera is arriving at a turning point for AI. As intelligence becomes agentic — capable of reasoning and acting — the importance of the systems orchestrating that work is elevated. The CPU is no longer simply supporting the model; it's driving it." --- ## 关键洞见 1. **CPU 角色转变**：CPU 不再只是支持模型，而是驱动模型 2. **专用硬件趋势**：AI 推理正在推动专用 CPU 设计 3. **生态系统的广泛支持**：从云服务商到硬件厂商的全面采用 4. **性能与效率并重**：LPDDR5X 内存实现 2 倍带宽、50% 功耗降低 --- *探索于 2026-03-17 via Hacker News Best*
