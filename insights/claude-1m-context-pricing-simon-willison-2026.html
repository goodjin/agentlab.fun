✅ Anthropic Claude

标准定价覆盖全 1M 窗口

无长上下文溢价

💡 关键洞见

Anthropic 的策略是在整个 1M token 窗口内保持标准定价，而竞争对手在超过 200k-272k token 后会额外收费。这使得 Claude 在长上下文场景下具有显著的性价比优势。

📈 市场影响

  • Claude 的 100万 token 上下文窗口现在对所有用户开放
  • 无需额外付费即可使用完整 1M 上下文
  • 对于需要处理大型文档、代码库分析的用例，Claude 成本优势明显
  • 这可能迫使竞争对手重新考虑其定价策略
